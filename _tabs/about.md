### Professional Overview

I am an offensive security professional specializing in **Web & Mobile Application Penetration Testing**, **Active Directory Exploitation**, and **Vulnerability Research**. My work focuses on evaluating high-risk enterprise applications, identifying critical business logic flaws, authorization bypasses, and chained attack vectors before malicious actors can exploit them.

Beyond security assessments, I am deeply committed to technical education: deconstructing foundational security literature into practical, actionable blueprints and building automation tooling that simplifies complex testing workflows.

### Core Areas of Specialization

#### 1. Web & API Penetration Testing
* **OWASP Top 10 Exploitation**: In-depth testing for Business Logic Flaws, Insecure Direct Object References (IDOR), Server-Side Request Forgery (SSRF), Server-Side Template Injection (SSTI), and Remote Code Execution (RCE).
* **API Security Architecture**: RESTful, GraphQL, and SOAP API vulnerability analysis, token security evaluation (JWT misconfigurations, OAuth 2.0 flow flaws), and rate-limiting bypasses.
* **Authentication & Session Management**: Privilege escalation, token leakage, and CORS/CSRF exploitation.

#### 2. Mobile Application Security (Android & iOS)
* **Static & Dynamic Analysis**: Reverse engineering compiled APK and IPA binaries using **Jadx**, **Ghidra**, and **Radare2**.
* **Runtime Manipulation**: Advanced instrumentation and security controls bypass (SSL Pinning, Root/Jailbreak Detection, Integrity Checks) using **Frida**, **Objection**, and **Medusa**.
* **Internal Architecture Auditing**: Insecure data storage (KeyStore, SharedPreferences), IPC Binder security, Content Provider leakage, and deep link hijacking.

#### 3. Active Directory & Enterprise Red Teaming
* **Internal Reconnaissance & Attack Path Mapping**: BloodHound and SharpHound graph analysis to identify stealthy privilege escalation vectors.
* **Identity Attacks**: Kerberoasting, AS-REP Roasting, Pass-the-Hash (PtH), Pass-the-Ticket (PtT), and Unconstrained/Constrained Delegation abuse.
* **AD CS Misconfigurations**: Identification and exploitation of vulnerable certificate templates (ESC1 through ESC13) for domain admin takeover.

#### 4. Security Tooling & Automation
* Developing custom offensive tools, DNS enumeration engines, and reconnaissance pipelines using **Python** and **Bash**.
* Automated OSINT correlation, attack surface mapping, and vulnerability scanning workflows.

### Security Methodology & Philosophy

1. **Beyond Automated Scanners**: Automated tools catch low-hanging fruit; human adversaries exploit context. Real-world security testing requires contextual reasoning, manual verification, and understanding the business architecture behind the code.
2. **Adversary Emulation**: Thinking from the perspective of an advanced threat actor—correlating seemingly minor low-severity findings into end-to-end compromise chains.
3. **Actionable Remediation**: A penetration test is only as good as its remediation guidance. Every finding must provide engineers with clear, reproducible steps and architectural solutions to eliminate vulnerabilities at the root cause.
